개인정보처리방침

시행일: 2026년 9월 23일 · 최종 수정일: 2026년 9월 26일

stock-trend는 운영자 본인의 주식 추세 기록·계산을 위한 개인용 도구입니다. 이 방침은 앱이 Google 계정 및 Google Drive 정보를 사용하는 방식과 이 안내 홈페이지에 적용됩니다.

1. 접근하는 정보와 목적

  • Google 계정 이메일: 사용자가 선택한 저장 계정과 실제 로그인한 계정이 일치하는지 확인합니다.
  • Google OAuth 인증 정보: 사용자가 동의한 Drive 접근을 수행하고, 자동 실행 시 접근 토큰을 갱신하는 데 사용합니다. Google 계정 비밀번호는 앱이 수집하거나 저장하지 않습니다.
  • 앱 전용 Drive 파일과 파일 정보: 주가 기록, 계산 상태, 처리 거래일, 발송 진행 상태 등을 담은 데이터베이스와 파일 식별자·체크섬·앱 속성을 읽고 씁니다.
  • 주가·종목 정보: 공개 제공처에서 수집한 시장 데이터로 추세 조건을 계산합니다. Google Drive의 다른 개인 문서를 주가 수집 원천으로 사용하지 않습니다.
  • 카카오 연결 정보: 카카오 연결 기능 사용 시 본인 인증 토큰과 메시지 전송 진행 상태를 결과 전달 목적으로 처리합니다. 현재 카카오 연결과 발송 기능은 개발·검증 중입니다.

2. Google 접근 권한

앱은 drive.file 권한을 요청합니다. 이는 앱이 생성한 파일이나 사용자가 해당 앱에 접근을 허용한 파일을 다루기 위한 권한입니다. 모든 Drive 파일에 대한 전체 읽기 권한, Gmail 또는 연락처 권한은 요청하지 않습니다.

3. 저장 장소와 보호

연결 준비 과정의 인증 정보와 검증 자료는 운영자의 로컬 컴퓨터에 저장됩니다. 자동 실행에서는 비공개 GitHub 저장소의 실행 환경을 사용하고 인증 정보는 GitHub Secrets 등 실행에 필요한 비밀 저장소에 보관하도록 구성합니다. 인증 파일과 토큰은 공개 저장소, 홈페이지 또는 로그에 게시하지 않습니다.

계산 데이터베이스는 사용자가 연결한 Google Drive에 최신본과 직전 정상본을 보관합니다. 카카오 토큰의 원격 보관이 필요한 경우에는 암호화하고, 암호화 키는 별도로 관리합니다. 실행 환경의 임시 자료는 작업 처리에 필요한 동안 사용합니다.

4. 외부 서비스 이용과 공개 범위

Google은 로그인과 Drive 저장, GitHub는 홈페이지 제공 및 자동 실행, 카카오는 본인 메시지 전달을 위해 이용됩니다. 각 서비스에는 기능 수행에 필요한 정보가 전달될 수 있으며 해당 서비스의 정책도 적용됩니다. 개인 Drive 파일과 인증 정보는 이 공개 홈페이지에 포함하지 않습니다. 카카오로는 선정 종목과 계산된 지표 등 알림 내용을 보냅니다.

Google에서 얻은 사용자 데이터를 판매하거나 광고·사용자 프로파일링·범용 AI 모델 학습에 사용하지 않습니다. Google API로 받은 정보의 사용 및 다른 앱으로의 이전은 제한적 사용 요건을 포함한 Google API Services User Data Policy를 준수합니다.

5. 보관 기간과 삭제 방법

Drive의 계산 자료와 인증 정보는 사용자가 앱을 이용하는 동안 유지합니다. 가격 자료는 계산에 필요한 최근 구간과 기준가·상태를 중심으로 보관하고 날짜별 백업을 계속 누적하지 않습니다.

  • Google 연결은 Google 계정의 서드 파티 연결 관리에서 해제할 수 있습니다.
  • 이용을 종료할 때는 예약 실행을 먼저 중지하고, 본인 Drive의 stock-trend 폴더와 필요하지 않은 로컬 자료를 삭제할 수 있습니다.
  • 로컬 인증 파일과 자동 실행용 Secrets에 저장한 토큰도 삭제할 수 있습니다. 연결 해제만으로 기존 데이터 파일이 자동 삭제되지는 않습니다.
  • GitHub 실행 기록 및 Google Drive 휴지통 등에 남은 정보는 각 서비스의 보관·삭제 정책에 따라 처리됩니다.

6. 홈페이지 방문 정보

이 홈페이지는 가입 폼, 광고, 자체 분석 스크립트, 추적 쿠키를 사용하지 않습니다. 호스팅 제공자인 GitHub는 서비스 제공 및 보안을 위해 방문자의 IP 주소 등 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요.

7. 변경 안내

기능 또는 데이터 처리 방식이 바뀌면 이 페이지와 최종 수정일을 갱신합니다. 추가 Google 권한이 필요한 경우에는 사용자의 동의를 다시 받습니다.
